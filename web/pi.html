The Pi has no automatic rules: every output (tower lamps, buzzer) is controlled by FMS job "Pin" steps. The buttons here are only for manual testing. One tower color is lit at a time. The push button is a simulated "world" input: it changes the input pin level and goes through the same edge-callback path as a real sensor, and its state is reported to FMS.
